# Indoor Routing Annotation Rules

실내 안내도 기반 annotation을 만들 때는 좌표를 많이 찍는 것보다, 실제 보행 가능한 표현 위에만 그래프를 얹는 것이 우선이다.

## Node Rules

1. 계단 혹은 에스컬레이터는 시작점과 끝점을 먼저 찾는다.
2. 계단/에스컬레이터 구간의 edge는 계단 표현 밖으로 나가지 않도록 만든다.
3. 계단 중간에 층계참이 보이거나 방향이 바뀌면 중간 노드를 추가한다.
4. 평평한 통로에는 통로 가운데에 노드를 둔다.
5. 평평한 통로가 길면 한 번에 긴 edge를 만들지 않고, 적절히 n분할해서 중간 노드를 둔다.
6. 꺾이는 지점, 분기점, 합류점, 승강장 연결부, 엘리베이터 연결부는 노드로 만든다.
7. 안내도에 화살표가 있는 경우 화살표의 중심선을 따라 노드를 찍는다.

## Edge Rules

1. edge는 화살표 위, 평평한 보행 통로, 계단/에스컬레이터 표현 위에만 생성한다.
2. 흰 빈 공간, 벽, 장식, 텍스트 영역, 계단 표현 밖을 가로지르는 edge는 만들지 않는다.
3. 계단/에스컬레이터 edge는 시작점, 끝점, 필요하면 층계참 노드를 순서대로 연결한다.
4. 긴 직선 통로 edge는 실제 거리 비용이 과도하게 뭉개지지 않도록 중간 노드로 나눈다.
5. 화살표가 꺾이면 edge도 꺾이는 노드를 거쳐 연결한다.
6. 서로 가까워 보여도 안내도상 연결 통로가 없으면 edge를 만들지 않는다.

## Coordinate Policy

1. 내부 routing graph는 EPSG 좌표로 직접 변환하지 않는다.
2. 노드는 이미지/층별 로컬 좌표를 기준으로 둔다.
3. edge 비용은 `distance_px * scale` 기반의 로컬 metric 거리로 계산한다.
4. 이미지가 기울어진 3D 안내도를 2D로 압축한 형태이므로, 필요하면 축별 scale 보정이나 계단/층간 비용 보정을 적용한다.
5. 출입구 등 외부 연결점만 실제 좌표와 연결하고, 내부 노드는 상대 좌표계를 유지한다.
